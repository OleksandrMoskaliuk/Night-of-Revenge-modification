# Night of Revenge Modpack

A collection of BepInEx plugins for **Night of Revenge** that enhances combat responsiveness, enemy encounters, passive stat regeneration, and gameplay dynamics.

---

## Included Modifications

- **[NoR Immersive Ero Mod](https://github.com/OleksandrMoskaliuk/Night-of-Revenge-modification/releases/tag/nor_bonedmod_improved_v0.1a)**: Overhauls combat, pleasure mechanics, elite enemy behaviors, and encounter dynamics.
- **[Night of Revenge Slave Respawn Mod](https://github.com/OleksandrMoskaliuk/Night-of-Revenge-modification/releases/tag/NoR_Slave_Respawn_Mod_v1.0)**: Allows rescued slave girls to re-appear across level restarts so they can be saved multiple times.
- **[Night of Revenge Regeneration Mod](https://github.com/OleksandrMoskaliuk/Night-of-Revenge-modification/releases/tag/NoR_Regeneration_v1.0.1)**: Grants dynamic passive regeneration for HP, MP, SP, and Pleasure status based on character stats and encounter metrics.
- **[Night of Revenge Elite Enemies Mod](https://github.com/OleksandrMoskaliuk/Night-of-Revenge-modification/releases/tag/NoR_Elite_Enemies_v0.1)**: Spawns elite enemies with randomized health multipliers, increased speed, EXP boosts, and color tinting.
- **[Night of Revenge Parry Mod](https://github.com/OleksandrMoskaliuk/Night-of-Revenge-modification/releases/tag/NoRParryMod_v1.0)**: Enhances guard mechanics by allowing attack/spell cancels into immediate blocks and resetting guard time on successful parries.
- **[NoR Fast Spell Cast Mod](https://github.com/OleksandrMoskaliuk/Night-of-Revenge-modification/releases/tag/NoRFastSpellCastMod_v1.0)**: Accelerates spellcasting speed by ~30% for faster magic book usage and skill responsiveness.
- **[Night of Revenge Berserk Mod](https://github.com/OleksandrMoskaliuk/Night-of-Revenge-modification/releases/tag/NoRBerserkMod_101)**: Dynamically boosts player stat multipliers (damage, speed, dash range, defense) as health decreases.

---

## Requirements

- **[BepInEx v5.4.23.5](https://github.com/bepinex/bepinex/releases)**: Requires the **x86 (32-bit)** version for Windows. Note: The x64 (64-bit) version is not supported.

---

## General Installation

1. Download and extract **BepInEx v5.4.23.5 (x86)** into your game root folder.
2. Run the game once to allow BepInEx to generate its default configuration and folder structure.
3. Download the desired `.dll` plugins from the [Releases](https://github.com/OleksandrMoskaliuk/Night-of-Revenge-modification/releases) page.
4. Place the `.dll` files into the `NightofRevenge/BepInEx/plugins` folder.
5. Launch the game. Configuration files (`.cfg`) for each active mod will be automatically generated in `NightofRevenge/BepInEx/config/`.
